A streaming text-processing pipeline that analyzes large documents without full in-memory loading.

- Case-normalized word frequency analysis and long-tail term exploration via configurable thresholds.
- Applied to 19th-century literary texts sourced from Project Gutenberg.
- **Tech:** Python, file I/O, basic NLP preprocessing.
