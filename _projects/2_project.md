An object-oriented metro network simulator built on weighted graph abstractions.

- Computed shortest commuter routes and travel times, including transfer costs and network constraints.
- Simulated disruption scenarios (e.g., station closures) and quantified changes in average journey time.
- Designed extensible components to support additional behaviours and commuter-specific policies.
- **Tech:** Python, OOP, graph algorithms, simulation modelling.
