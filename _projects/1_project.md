A PDF-based QA assistant that returns retrieval-grounded summaries and answers instead of relying on parametric memory alone.

- Implemented an end-to-end RAG workflow: **load → split → embed → index → retrieve → answer**.
- Improved answer reliability by grounding responses in retrieved passages.
- **Tech:** Python, LangChain, ChromaDB, embedding models.
